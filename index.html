C Profile
Open source · Beginner friendly · MIT licensed

Card UI effects you can copy, ship and contribute

CardUi is a free, community-built library of hover, flip, glow and glass cards. Built with plain HTML, CSS and a pinch of JavaScript, so anyone can use it, and anyone can add to it.

Explore designs → Star on GitHub

Open source

MIT licensed and built in the open. Fork it, use it in any project, and send your own effects back.

Beginner friendly

No frameworks and no build step. If you know a little HTML and CSS, you can add your first card in an afternoon.

Easy to ship

Every effect has its HTML, CSS and JS one click away. Copy the snippet and drop it into your site.

How it works

1

Explore

Browse, filter by category, and search the collection of 25 community card effects.

2

Copy the code

Open the Code modal on any card to copy its HTML, CSS and JS in one click.

3

Ship it

Paste it into your project, tweak the colours and fonts, and go live.

Contribute your own card

1

Fork the repo

Fork CardUI on GitHub and clone it to your computer.

2

Add your card

Add your markup, CSS and JS in your own marked sections. Don’t change existing cards.

3

Open a pull request

Send it in and see your name on the live Contributors leaderboard.
